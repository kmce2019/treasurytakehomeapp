Scope, privacy & practical limits

This standalone prototype compares application data with label artwork; it is not a complete regulatory rules engine or an official Treasury/TTB service. English text is supported. Photograph glare, curved bottles, tiny print and unusual layouts may reduce accuracy. Use clear artwork; rotate sideways images before running OCR.

Matching text anywhere on the supplied panels is evidence of presence, not proof of correct placement. Producer/address abbreviations and ambiguous values require human review. Warning boldness, body font weight, layout, contrast, and physical type size always need an agent check.

The target is about five seconds per clear label after initialization, not a guaranteed response time. First use downloads the model from this site. Results and images stay in page memory and disappear on refresh. Export before leaving. Hosting access logs may record ordinary page requests; uploaded label contents are not transmitted.
